What's new in v1.3.1 (over v1.3.0)
-----------------------------------
- v0x02 secrets envelope (ADR-0010): the per-envelope nonce is
  now the scrypt KDF salt, so identical plaintexts no longer
  share KDF inputs. `DHC1` envelopes from v1.2.0/v1.3.0 remain
  readable. `SecretsService` gains `get_raw` / `put_raw` for
  binary round-trip; `ModelConfigStore` uses them.
- Per-session `ModelConfig` (ADR-0011): temperature,
  max_tokens, top_p, system_prompt stored encrypted in
  `SecretsService` under `model_config_{session_id}`. C7 reads
  the config and forwards the knobs to the live provider.
- 2 new C1 routes: `GET /api/sessions/{id}/config` and
  `POST /api/sessions/{id}/config`.
- `<SettingsModal>` React component: per-provider API key
  entry, update, delete. No `prompt()` / `alert()` /
  `confirm()` (all in-component React state).
- `<ModelConfigMenu>` React component: range sliders for
  temperature / max_tokens / top_p and a system prompt
  textarea. Wired to the new config routes.
- `StreamChunk.usage` field: optional
  `{prompt_tokens, completion_tokens, total_tokens}` on the
  final chunk of a stream. OpenAI and OpenRouter yield it via
  a choices-less trailing SSE chunk; Anthropic yields it from
  `message_delta`.
- vitest frontend test runner: `apps/web/package.json` `test`
  script runs `vitest run`. 8 React component tests in CI.
- 2 new ADRs: 0010 (per-secret nonce), 0011 (model config
  storage).
- Test count: 388 → 430 (+42: +34 Python, +8 vitest).

Envelope versions (ADR-0010)
----------------------------
  v0x01  (DHC1)  fixed scrypt salt  — v1.2.0/v1.3.0 writes
  v0x02  (DHC2)  per-envelope nonce — v1.3.1 writes
Both layouts are `HEADER (4) || nonce (16) || ct (n) || tag (32)`.
`open_envelope` dispatches on the header.

C1 routes
---------
v1.1.0 (unchanged):
  GET    /                       static index.html with embedded <meta name="dhc-token">
  GET    /healthz                modules + discovered plugins + loaded plugins
  GET    /ws                     WebSocket event stream (token in query, loopback origin)
  GET    /api/manifest           full manifest (modules + plugins)
  GET    /plugins                discovered vs loaded plugins
  POST   /plugins/{id}           load a plugin
  DELETE /plugins/{id}           unload a plugin
  GET    /prompts                list 10 master prompts (requires prompt_browser_v1)
  GET    /prompts/{key}          single prompt body
  POST   /api/eval               offline in-proc eval of pasted code

v1.2.0:
  WS     /ws/chat                chat request/response (bearer token + loopback origin)
  GET    /api/llm/health         LLM adapter reachability
  GET    /api/sessions           list session summaries (?q= full-text, ?search= legacy)
  POST   /api/sessions           create a session
  GET    /api/sessions/{id}      full session
  PATCH  /api/sessions/{id}      rename/pin/archive/tag/set-model
  DELETE /api/sessions/{id}      soft-delete (or ?hard=1 to remove file)
  POST   /api/sessions/{id}/messages  send a turn; returns assistant message
  GET    /api/secrets            list names only (NEVER values)
  PUT    /api/secrets/{name}     encrypt and store
  DELETE /api/secrets/{name}     remove

v1.3.0 (new):
  GET    /api/models             list 6 hardcoded models (ADR-0006)
  GET    /api/models/{id:.+}     fetch a single model

v1.3.1 (new):
  GET    /api/sessions/{id}/config   read per-session ModelConfig (ADR-0011)
  POST   /api/sessions/{id}/config   write per-session ModelConfig
