## 11. Test infrastructure additions

- A new `tests/integrations/__init__.py` package marker.
- A new `tests/integrations/_mock_provider_server.py` helper: a hand-rolled aiohttp server factory that returns canned SSE responses for `/v1/chat/completions` (OpenAI shape) and `/v1/messages` (Anthropic shape). Reused by the 3 client test files.
- No new test dependencies (no `aioresponses`, no `respx`). We use the same pattern as the v1.2.x mock LLM.
