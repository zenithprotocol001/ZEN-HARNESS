What's new in v1.3.0 (over v1.2.1)
-----------------------------------
- 3 live LLM provider clients (OpenAI, Anthropic, OpenRouter)
  behind an LLMProvider abstract base, with a 3-attempt, 1 s/2 s
  linear retry policy (5xx + network errors only, no 4xx retry).
- ModelRegistry with 6 hardcoded models across 4 providers
  (mock-llm/default, openai/gpt-4o-mini, openai/gpt-4.1,
  anthropic/claude-3-5-sonnet-latest, anthropic/claude-3-5-haiku-latest,
  openrouter/auto).
- C7 dispatch: LLMStreamAdapter accepts optional model_registry +
  secrets_service; live dispatch when both are set and the model
  is not the mock.
- 2 new C1 routes: GET /api/models, GET /api/models/{id} (with
  regex constraint to allow slashes in the id).
- <ModelSelect> React component in the chat header, persisted
  per-session via PATCH /api/sessions/{id} with {"model": ...}.
- 3 new docs (v1.3.0-technical-spec, v1.3.0-test-plan, and
  3 new ADRs: 0007, 0008, 0009).
- Test count: 318 → 388 (+70).

C1 routes
---------
v1.1.0 (unchanged):
  GET    /                       static index.html with embedded <meta name="dhc-token">
  GET    /healthz                modules + discovered plugins + loaded plugins
  GET    /ws                     WebSocket event stream (token in query, loopback origin)
  GET    /api/manifest           full manifest (modules + plugins)
  GET    /plugins                discovered vs loaded plugins
  POST   /plugins/{id}           load a plugin
  DELETE /plugins/{id}           unload a plugin
  GET    /prompts                list 10 master prompts (requires prompt_browser_v1)
  GET    /prompts/{key}          single prompt body
  POST   /api/eval               offline in-proc eval of pasted code

v1.2.0:
  WS     /ws/chat                chat request/response (bearer token + loopback origin)
  GET    /api/llm/health         LLM adapter reachability
  GET    /api/sessions           list session summaries (?q= full-text, ?search= legacy)
  POST   /api/sessions           create a session
  GET    /api/sessions/{id}      full session
  PATCH  /api/sessions/{id}      rename/pin/archive/tag/set-model
  DELETE /api/sessions/{id}      soft-delete (or ?hard=1 to remove file)
  POST   /api/sessions/{id}/messages  send a turn; returns assistant message
  GET    /api/secrets            list names only (NEVER values)
  PUT    /api/secrets/{name}     encrypt and store
  DELETE /api/secrets/{name}     remove

v1.3.0 (new):
  GET    /api/models             list 6 hardcoded models (ADR-0006)
  GET    /api/models/{id:.+}     fetch a single model
